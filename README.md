# Estrutura de Dados

Este repositório reúne as implementações, exercícios e projetos desenvolvidos durante a disciplina de **Estrutura de Dados**.

## Objetivo

Consolidar os conceitos estudados na disciplina por meio da implementação e utilização de diferentes estruturas de dados e algoritmos relacionados.

## Conteúdo

O repositório inclui implementações e atividades envolvendo:

* Revisão de programação em Python;
* Tipos de dados, tipos abstratos e estrutura de dados;
* Noções de análise de algoritmos e notação assintótica;
* Recursividade;
* Listas Encadeadas;
* Pilhas e Filas;
* Árvores binárias e árvores binárias de busca;
* Árvores balanceadas AVL e rubro-negras;
* Tabela Hash;
* Filas de prioridade e heaps.
